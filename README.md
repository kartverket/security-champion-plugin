# Security Champion Plugin
Security champion plugin is used in [Kartverket.dev](https://github.com/kartverket/kartverket.dev) to show the security champion for a repository and enable the user to change a security champion from within backstage. It is published as a [NPM package](https://www.npmjs.com/package/@kartverket/plugin-security-champion?activeTab=readme) and more information on how to run the plugin can be found in the [plugin readme file](https://github.com/kartverket/security-champion-plugin/blob/main/plugins/security-champion/README.md). This repository contains code from Kartverket.dev in order to run and test the plugin locally before publishing it to NPM. Kartverket.dev is Kartverket's developer portal. It is built using [Backstage](https://backstage.io/), and helps Kartverket's internal developers discover and use Kartverket's APIs and services. We direct you to the [CONTRIBUTING.md](./CONTRIBUTING.md) file in Kartverket.dev in order to set up the code and get started with Kartverket.dev specific configuration.
